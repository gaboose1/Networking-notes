# Networking Notes

A beginner-friendly collection of networking notes covering fundamental networking concepts, IP addressing, protocols, ports, network devices, IPv4, and IPv6.

## Project Purpose

This project is designed as a simple reference for learning and reviewing basic computer networking concepts.

## Topics

- Networking basics
- IP addressing
- Protocols and ports
- Network devices
- IPv4
- IPv6

## How to Use

Open the Markdown files inside the `notes` directory and read the topic you want to review.
