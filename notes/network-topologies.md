# Network Topologies

Network topology describes how devices and connections are arranged in a network.

## Star Topology

In a star topology, devices connect to a central device such as a switch.

### Advantages

- Easy to manage
- Easy to troubleshoot
- Failure of one cable usually affects only one device

### Disadvantage

If the central device fails, communication between connected devices can be affected.

## Bus Topology

In a bus topology, multiple devices share a single communication cable.

### Advantages

- Simple design
- Requires less cable

### Disadvantages

- A problem with the main cable can affect the network
- Troubleshooting can be difficult

## Ring Topology

In a ring topology, devices are connected in a circular arrangement.

### Advantages

- Data can follow an organized path
- Each device has a defined connection

### Disadvantages

- A failure in the ring can affect communication
- Changes to the network can be difficult

## Mesh Topology

In a mesh topology, devices have multiple connections to other devices.

### Advantages

- High redundancy
- Good fault tolerance

### Disadvantage

It can require more cables and hardware, making it more expensive and complex.

## Summary

Different topologies are suitable for different network requirements. Star topology is commonly used in modern Ethernet networks because it is easier to manage and troubleshoot.
