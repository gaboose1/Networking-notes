# Network Devices

Network devices are hardware components that help computers and other devices communicate with each other.

## Switch

A switch connects devices within a local network.

It uses MAC addresses to forward Ethernet frames to the appropriate device.

## Router

A router connects different networks and forwards packets between them.

For example, a home router can connect a local network to the Internet.

## Access Point

An access point provides wireless network connectivity to devices such as laptops and smartphones.

## Modem

A modem provides communication between a local network and an Internet service provider's network.

## Firewall

A firewall monitors and controls network traffic according to security rules.

It can help prevent unauthorized network access.

## Network Interface Card

A Network Interface Card (NIC) allows a device to connect to a network.

A NIC may provide either wired Ethernet connectivity or wireless connectivity.

## Summary

Common network devices include:

- Switch
- Router
- Access Point
- Modem
- Firewall
- Network Interface Card (NIC)
