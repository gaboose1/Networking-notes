# Common Network Threats

## Malware

Malware is malicious software designed to damage systems, steal information, or gain unauthorized access.

Examples include viruses, worms, trojans, and ransomware.

## Phishing

Phishing is a social engineering technique where attackers attempt to trick users into revealing sensitive information or opening malicious content.

## Denial-of-Service

A Denial-of-Service (DoS) attack attempts to make a service unavailable by overwhelming it with traffic or requests.

## Man-in-the-Middle

A Man-in-the-Middle (MITM) attack occurs when an attacker secretly intercepts communication between two parties.

## Password Attacks

Attackers may attempt to gain access to accounts by guessing passwords, using stolen credentials, or performing automated password attacks.

## Spoofing

Spoofing occurs when an attacker pretends to be a trusted device, user, or service.

## Basic Protection

Some basic defensive measures include:

- Use strong passwords.
- Enable multi-factor authentication.
- Keep systems updated.
- Use secure network connections.
- Be careful with unexpected links and attachments.
- Monitor network activity.
- Limit unnecessary network access.

## Summary

Understanding common network threats helps users and administrators recognize risks and apply appropriate security controls.
