# Network Security

## What Is Network Security?

Network security is the practice of protecting networks, devices, and data from unauthorized access, misuse, and attacks.

## Common Security Controls

### Firewall

A firewall monitors and controls network traffic based on defined security rules.

### Access Control

Access control ensures that only authorized users and devices can access network resources.

### Encryption

Encryption protects data by converting readable information into a form that unauthorized users cannot easily understand.

### Authentication

Authentication verifies the identity of a user or device before allowing access to a system or network resource.

### Network Segmentation

Network segmentation divides a network into separate sections to limit access and reduce the impact of security incidents.

## Basic Security Practices

- Use strong and unique passwords.
- Enable multi-factor authentication when available.
- Keep operating systems and software updated.
- Use firewalls and security tools.
- Avoid connecting to untrusted networks.
- Monitor unusual network activity.

## Summary

Network security combines technologies, configurations, and security practices to protect network resources and data from unauthorized access and attacks.
