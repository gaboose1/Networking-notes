# Network Security Checklist

Use this checklist when reviewing the basic security of a network.

## Account Security

- Use strong and unique passwords.
- Enable multi-factor authentication.
- Remove unused accounts.
- Give users only the access they need.

## Device Security

- Keep operating systems updated.
- Install security updates regularly.
- Use a firewall.
- Use trusted security software.

## Network Security

- Secure Wi-Fi with a strong password.
- Use encryption where appropriate.
- Separate sensitive systems from less trusted networks.
- Monitor unusual network activity.

## User Awareness

- Avoid suspicious links and attachments.
- Verify unexpected requests for sensitive information.
- Be careful when using public Wi-Fi.

## Final Check

A secure network requires regular monitoring, updates, access control, and user awareness.
